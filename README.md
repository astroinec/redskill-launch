## 使用

每个目录的入口是 `SKILL.md`，可用文本编辑器阅读。它们是供支持相应格式的工具读取的内容模板，不是可执行程序。本次发布未安装、激活或执行这些模板，也未向任何平台提交、发送邮件或发布笔记。

示例中的称呼、数字和场景仅用于说明，不能作为真实经历、实时价格、实测口碑或身份材料使用。涉及个人经历时先去掉姓名、联系方式、学号和第三方隐私；输出仍需人工核实。

## 发布范围

仅收录八个模板与本说明。旧上传指南、发布日程、运营计划、教程笔记及系统文件未纳入，避免把私人运营工作稿与可复用模板混在一起。不会因阅读本仓库自动安装其他技能或依赖。

没有新增开源许可证；模板中的网络句式、平台名称及其他第三方内容不因公开归档取得再分发授权。旧指南提及的平台文档摘要也未上传。示例真实性与引用权属仍需使用者自行确认。

本次做 Markdown 入口、front matter、相对链接和敏感信息检查，没有执行提示词内容，也未验证平台可导入性。
